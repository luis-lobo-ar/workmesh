Install WorkMesh

Use the current standalone repository for source and Releases for prebuilt binaries. The former luislobo/workmesh repository retains historical releases through 0.3.9.

Install the Linux snapshot

  1. Open Releases and select a snapshot-<standalone-commit> prerelease. Current downloads target Linux x86_64 and build on Ubuntu 24.04.
  2. Download workmesh-linux-x86_64.tar.gz and its .sha256 file into the same directory.
  3. In that directory, verify and extract the archive.
sha256sum --check workmesh-linux-x86_64.tar.gz.sha256
tar -xzf workmesh-linux-x86_64.tar.gz

The checksum command must report OK. Install both executables into a directory on your PATH.

install -Dm755 workmesh-linux-x86_64/bin/workmesh "$HOME/.local/bin/workmesh"
install -Dm755 workmesh-linux-x86_64/bin/workmesh-mcp "$HOME/.local/bin/workmesh-mcp"
workmesh --version
workmesh-mcp --version

If your shell cannot find the commands, add $HOME/.local/bin to PATH. Both version strings must identify the selected standalone commit. The Git commit count can differ between a full source checkout and GitHub's shallow checkout.

The archive includes mesh-export.json, license notices, and both binaries. The manifest records the authoritative Mesh source revision and exported file hashes.

Build from source

Install Git and the stable Rust toolchain, then run these commands.

git clone https://github.com/luis-lobo-ar/workmesh.git
cd workmesh
cargo build --locked --release -p workmesh -p workmesh-mcp
target/release/workmesh --version
target/release/workmesh-mcp --version

To install from the checkout, use Cargo.

cargo install --locked --path opt/workmesh/crates/workmesh-cli
cargo install --locked --path opt/workmesh/crates/workmesh-mcp

WorkMesh includes its required Mesh libraries. It does not require AgentMesh, Telegram, or another Mesh service. Other platforms require a source build and are not validated by the Linux release workflow.

Check the GitHub build

In the standalone repository, .github/workflows/product.yml tests WorkMesh and its bundled libraries, builds workmesh and workmesh-mcp, runs both version commands, and packages the binaries with notices and a checksum. A successful main build publishes an immutable snapshot prerelease. Pull requests run build checks without publishing a release. See GitHub Actions for results.

In the Mesh monorepo, .github/workflows/workmesh-build.yml runs package checks and uploads operator build artifacts. The YAML files under docs/reference/ describe the former standalone workflows and are historical references.

Snapshot publication preserves the current product version, currently 0.4.0. The snapshot tag and binary Git suffix identify the exact standalone revision. Releases through 0.3.9 remain in the former repository.
